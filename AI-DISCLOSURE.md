# AI / Super Intelligence (SI) Use Disclosure

This project was built with the help of an AI coding assistant — **Claude Code**
(Anthropic's Claude, a large language model) — under the direction and review of myself. In line with the NASA
Space Apps Challenge rules on Super Intelligence (SI) tools, here is exactly where
and how SI was used.

## Where SI was used

- **Code** — The application's source code (React + TypeScript front-end, Python and FastAPI, and the build/deploy configuration) was written with AI
  assistance, then directed, reviewed, and tested by me. This is also
  recorded in version-control **metadata**: few but some git commits carry a
  `Co-Authored-By: Claude …` trailer.
- **Written content** — The README and the Space Apps submission write-ups were
  drafted with AI assistance and edited by myself.
- **Presentation** — The demo deck was generated
  with AI assistance; its visuals are screenshots of the app.

## NASA branding

No NASA logos, flags, or mission identifiers appear in any AI-generated content.
